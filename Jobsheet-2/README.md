### RINGKASAN

1. Menambahkan direktori assets
    * Direktori assets biasanya berisi asset yang digunakan pada web seperti file styles.css, folder picture, dan asset lain yang diperlukan.

2. Menambahkan tag `<link>` pada file htmml
    * Tag `<link>` ditambahkan pada bagian `<head` HTML untuk menghubungkan file HTML dengan file CSS di dalam folder assets/css.
